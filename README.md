# 🏦 Sistema de Empréstimo Bancário

Este projeto foi desenvolvido em Python como parte dos meus estudos em lógica de programação.

🎯 O objetivo foi simular um sistema de análise de empréstimos, permitindo o cadastro de um cliente, a definição do valor solicitado e da quantidade de parcelas, além da validação da aprovação do crédito com base em regras previamente estabelecidas.

Durante o desenvolvimento, busquei praticar conceitos fundamentais da linguagem Python, como variáveis, operadores matemáticos, estruturas condicionais (if, elif e else), entrada e saída de dados, além da construção de regras de negócio para representar um processo comum em instituições financeiras.

🚀 Funcionalidades
👤 Cadastro do cliente.
💵 Solicitação do valor do empréstimo.
📅 Definição da quantidade de parcelas.
📊 Cálculo do valor das parcelas.
✅ Análise da solicitação com base nas regras definidas.
📄 Exibição do resultado da análise e do resumo da operação.
🛠️ Tecnologias utilizadas
🐍 Python
🎓 Objetivo

Este projeto faz parte da minha evolução prática em programação, com foco no desenvolvimento do raciocínio lógico, na implementação de estruturas condicionais e na simulação de processos presentes no setor bancário.

Além de reforçar conceitos essenciais da linguagem Python, o projeto demonstra a aplicação da lógica de programação em um cenário real, aproximando o aprendizado das situações encontradas no mercado de tecnologia e análise de sistemas. 🚀
